## Tech Stack

- **Framework:** Laravel 13
- **Styling:** Tailwind CSS v4
- **Testing:** Pest v5
- **Build Tool:** Vite 8

## Getting Started

```bash
# Install dependencies
composer setup

# Run the dev server
composer dev
```

## Testing

```bash
composer test
```
